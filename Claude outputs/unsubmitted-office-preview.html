Unsubmitted work orders — the office side, as built

Two things, both already in v1.33.1: a red flag on the billing-hub row, and a once-a-morning pop-up on the dashboard. Same rule behind both.

1Billing hub — the flag on the row

The flag column is the one that already carries "Changed since invoiced" and "Awaiting PO". "Runner never submitted" sits there in the same red, and it outranks every other flag on that row — every other flag assumes the night was real. Hover it and it names the days. Clicking the row opens the work order like always.

Where it shows: any tab, any row whose work order has a past day still in progress — Needs review is where they'll land, since an unsubmitted night is usually an un-reviewed one. Once you approve the day on the work order (or the runner submits late) the flag drops off on its own. Nothing to click to clear it.

2Dashboard — the morning pop-up

First dashboard visit after 8:50 each morning, if there's anything in the last 14 days. Each row names who closed that studio that night. Tap a row → the work order opens right there. "Later today" puts it away until tomorrow; the billing flags stay regardless.
