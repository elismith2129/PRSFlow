How it works, all three
  • Order: Unranked → 3 → 2 → 1. Inside a group, longest since last follow-up goes first, so the list works itself top-down.
  • The tick = a follow-up. Ticking stamps who and when ("2d · EL"). Ticked since Monday = done this week, greyed out. Next Monday it un-greys on its own; the date stays.
  • Red date = no follow-up in 7+ days, or never.
  • Status colours keep their jobs (warm is warm, never a warning), so the rating uses its own light-to-bright steps instead of new colours.
  • Books → drops off. Older than 90 days → drops off.
