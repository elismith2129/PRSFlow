Invoice quick view

A small PDF chip beside the WO number on every row that has an invoice attached. Both options use the same chip; they differ in what the click opens. The package window (click the client) is untouched — that's the B&W render; this is the file that was dropped on the row.

A · Popover under the chip

lightest

Click the chip, the first page of the attached PDF floats right there; click anywhere else and it's gone. Open ↗ and Download live in its foot. Good for "is that the right invoice?" — the glance.

Same in both
  • The chip only appears when a file is attached (hasInvoiceDoc). No chip = nothing dropped yet — the row's flag cell already says "Drop invoice here".
  • Hover on the chip: invoice number + when it was attached + by whom.
  • The PDF is the stored file via a short-lived signed URL, same as ⋯ → Open today. Images (a photographed invoice) show as an image.
  • ⋯ → "Open the attached invoice PDF" stays — the findable home. The chip is the shortcut.
Build notes
  • No migration. invoice_doc_path already on the work order; signedInvoiceUrl() already exists.
  • A: one component, InvoicePeek, anchored to the chip, iframe of the signed URL, Esc / outside click closes.
  • B: a right drawer like the Notes sheet, keyed by workOrderId; ↑/↓ steps through the visible rows that have a file.
  • Package window unchanged. Mobile: both fall back to opening the PDF full-screen.
