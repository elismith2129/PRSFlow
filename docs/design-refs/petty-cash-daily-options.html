Petty cash — a real daily ledger

Today the runner page loads every entry that studio has ever made and calls the original seed "Opening balance". The office modal scopes to one day but still reads that seed as the day's opening, so its Closing Balance has never meant anything. Both are fixed by the same rule.

The rule

Cash is physical, so the count is the truth. The ledger resets to reality every time someone counts the box.

Today's opening = the most recent counted close, plus every entry logged since that count.

A skipped night doesn't break the chain — the next runner still opens at the last real count plus whatever was logged. If nobody has ever counted, it falls back to the seed the owner set when the log began.
