Why this one. The tech's day is "what's broken, where, and is it mine" — that is exactly the row. State-first grouping means the red section is the same place for every seat, and a page with nothing red is visibly healthy (the dashboard's data-emptiness law). The old Flags log survives as the top section, the old Tasks page as the middle; neither needs its own screen. Vendor + cost stay because the resolve flow already collects them and the money matters — but only where they mean something.

Rulings to confirm before CC touches anything

  1. Techs see every facility / gear / mics item, not only their seat's. Today's RLS is own-only for tech; it widens to "any item in a tech category". Client/billing and office stay seat-only.
  2. Age is the only alarm. No seat after 72h → hot. Nothing else on the page is red. Due dates show as text.
  3. "Acknowledge" retires. Picking up = acknowledged. "Not a real issue" closes with a note, no vendor/cost.
  4. Vendor + cost only for facility and gear. Everything else is done with an optional note.
  5. Mic QC becomes a source. A bad/missing mic on the runner mics page makes a mics item (source mic_qc). The Admin banner nobody owns goes away.
  6. Data stays in dashboard_tasks (+ studio, category, resolved_vendor, resolved_cost). flags remains the intake table and mirrors state, so the runner checklist, WO popup and Admin Flags tab keep working untouched.
  7. Rail: one item, Work, under Operations, replacing Flags and Tasks. Both old routes become redirect stubs.
  8. Name: "Work" is a placeholder. Alternatives: The Board, Fix It, Open Items.
