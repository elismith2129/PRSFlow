C · Financials — rent per day, from the lease
The reason Camper and MBA have work orders today is that Financials only reads studio_time_rows. Instead, tenants become their own stream: each lease's amount is straight-lined across its period's days. Mustard's $29,500 breaks down the same way. No WO needed for any of it, and Mustard's runner-hour rows carry no charge so nothing double counts.

D · What leaves the work-order world
The pipeline rule in one line: a lockout on a leased room is never an invoice. Two kinds of lease decide what else exists.
Unstaffed lease — Camper, MBA
Exists
  • Lease row
  • Calendar block so the room reads taken
  • Ledger period every cycle
Does not exist
  • Work order — none, ever
  • Day cards, runner duty
  • Billing / COD row
Staffed lease — Mustard
Exists
  • Lease row + incidentals line
  • Work order with day cards — runners type start/end daily
  • Runner hub card, missing-times gate as today
Does not exist
  • Charge on his rows — hours only
  • Billing / COD row — hidden from the pipeline like Tech / Tour / Open Hours
