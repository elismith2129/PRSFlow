Multi-day cards, round 2 — day cards that read as one booking

Three ways to tie the day cells together. All three: one card per run, same colour, same click, same hover; every day shows its own time and staff; days that match the day before are quieter. Only the linking differs.

B1The spine Recommended

A continuous darker band across the top carries the name, label and day count once. The day cells hang under it. You read the header first, then the days — the way a table reads.
